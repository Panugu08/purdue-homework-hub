Purdue Homework Hub

A web application designed to organize homework assignments from multiple Purdue course platforms into one centralized dashboard.

Current Status

Early development.

Planned Features
View assignments from multiple courses in one place
Organize assignments by due date
Filter assignments by course
Mark assignments as completed
Link directly to assignments
Eventually integrate with Purdue course platforms
